# Node.js 🚀

### My Journey into Backend Development

Welcome to my Node.js repository! 👋

This repository is a collection of my learning, practice, and experiments with **Node.js and backend development**. I am building my understanding of how servers work, how HTTP requests and responses are handled, and how backend applications communicate with clients.

Rather than just learning concepts theoretically, I believe in writing code, solving errors, and learning through practical implementation.

## 🛠️ Tech Stack

- **JavaScript** — Programming language
- **Node.js** — Server-side JavaScript runtime
- **HTTP Module** — Creating and handling web servers
- **HTML** — Building basic web pages and forms
- **Git & GitHub** — Version control and project management

## 📚 What I'm Learning

- Creating HTTP servers with `http.createServer()`
- Understanding requests (`req`) and responses (`res`)
- Working with URLs, HTTP methods, and headers
- Sending responses using `res.write()` and `res.end()`
- Setting response headers with `res.setHeader()`
- Handling HTTP status codes
- Implementing basic routing
- Understanding redirects
- Creating HTML forms and handling user input
- Exploring backend development fundamentals

## 🎯 My Goals

- Build a strong foundation in backend development.
- Understand client-server communication.
- Learn Express.js, middleware, and REST APIs.
- Connect backend applications with databases.
- Build practical projects and develop real-world problem-solving skills.
